STEP 6 - SpaderOptics App (optional, auxiliary)

Code:  SpaderOpticsApp.mlapp

The App reads the database and plots the quantities it contains.

TO USE THE APP WITHOUT RUNNING STEPS 1-5
1. Download SpaderOptics.mat from Zenodo, with doi: "10.5281/zenodo.23643910"
2. Copy it into this folder (it is not stored in the GitHub repository).
3. Open SpaderOpticsApp.mlapp in MATLAB (R2025b) and press Run.

If you built the database yourself with Step 5, copy your SpaderOptics.mat here instead.
